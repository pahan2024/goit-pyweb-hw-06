# Домашнє завдання #6. Реляційні бази даних (SQLite)

Цей проєкт містить реалізацію схеми бази даних для навчального закладу, скрипт для автоматичного заповнення бази випадковими даними за допомогою бібліотеки `Faker`, а також набір аналітичних SQL-запитів.

## 🛠️ Технологічний стек
* **СУБД:** SQLite
* **Мова програмування:** Python 3
* **Бібліотеки:** `faker`, `sqlite3`

---

## 🗂️ Структура бази даних (Схема)
База даних складається з 5 взаємопов'язаних таблиць:
1. **`groups`** — навчальні групи.
2. **`students`** — студенти (прив'язані до груп через `group_id`).
3. **`teachers`** — викладачі.
4. **`subjects`** — предмети (прив'язані до викладачів через `teacher_id`).
5. **`grades`** — оцінки студентів з предметів із зазначенням дати отримання.

---

## 🚀 Як запустити проєкт локально

### 1. Встановлення залежностей
Для генерації реалістичних українських імен та даних необхідно встановити пакет `Faker`:
```bash
pip install faker
```

### 2. Створення та заповнення бази даних
Запустіть скрипт генерації даних. Він автоматично створить файл бази даних `pyweb-hw-06.sqlite` (якщо його немає) та наповнить його випадковими даними (~40 студентів, 3 групи, 4 викладачі, 6 предметів та до 20 оцінок для кожного студента):
```bash
python seed.py
```

## 🔍 SQL-запити (Основні та додаткові)
Кожен запит оформлено в окремому файлі `query_X.sql` в корені проєкту:

* `query_1.sql` — 5 студентів із найбільшим середнім балом з усіх предметів.
* `query_2.sql` — Студент із найвищим середнім балом з певного предмета.
* `query_3.sql` — Середній бал у групах з певного предмета.
* `query_4.sql` — Середній бал на потоці (по всій таблиці оцінок).
* `query_5.sql` — Які курси читає певний викладач.
* `query_6.sql` — Список студентів у певній групі.
* `query_7.sql` — Оцінки студентов у окремій групі з певного предмета.
* `query_8.sql` — Середній бал, який ставить певний викладач зі своїх предметів.
* `query_9.sql` — Список курсів, які відвідує студент.
* `query_10.sql` — Список курсів, які певному студенту читає певний викладач.
* `query_11.sql` *(Додаткове)* — Середній бал, який певний викладач ставить певному студентові.
* `query_12.sql` *(Додаткове)* — Оцінки студентів у певній групі з певного предмета на останньому занятті.
